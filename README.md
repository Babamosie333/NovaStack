## About

This project is a modern and animated personal portfolio website designed to showcase my work, skills, experience, and development approach in a visually engaging way.

It is built with the latest Next.js App Router architecture and uses smooth UI animations, reusable components, interactive 3D visuals, and a responsive layout to create a strong personal brand presence.

---

## Features

- Modern dark-themed UI
- Responsive design for mobile, tablet, and desktop
- Animated hero section with spotlight effects
- Bento grid about section
- Interactive 3D globe section
- Recent projects showcase
- Client testimonials slider
- Work experience cards
- Development approach section
- Social links and contact CTA
- Smooth scrolling navigation
- Reusable UI component architecture
